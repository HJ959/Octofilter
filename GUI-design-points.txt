  Folder: ui/skins/ — put all your PNGs there.
  
  How to prepare them:
  
  1. Size: Design at 2× resolution (1400×900 px for a full background at our 700×450 default window). NanoVG will scale down cleanly.
  2. Format: PNG with transparency (RGBA). Use transparent backgrounds so textures can overlay the drawn UI.
  3. What to make:
    - background.png — full-window texture (paper grain, noise, subtle pattern)
    - field_bg.png — texture for the stereo field canvas area
    - knob_ring.png — circular texture behind each knob (optional)
    - panel_bg.png — texture for the bottom strip / right panel
    - Any decorative elements you fancy
  
  4. Blend mode guidance:
    - Light textures on dark background → use additive (NVG_LIGHTER) for glow
    - Dark textures (grain, scratches) → use normal blend with low opacity (20-40%)
    - Colour washes → use normal blend with the texture as a semi-transparent overlay
  
  5. Keep files small — under 500KB each ideally. Large PNGs increase plugin load time.
  6. Naming: keep it simple — background.png, noise_overlay.png, field_texture.png etc.
  
  When you've placed them in ui/skins/, I'll wire them up: embed them as C arrays (like the font), load with createImageFromMemory(), and draw them with the
  appropriate blend mode at the right positions.
